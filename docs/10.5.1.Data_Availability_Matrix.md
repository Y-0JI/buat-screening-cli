## Dampak ke Roadmap

- **Phase 1 + 2A (laporan inti):** data lengkap — harga, profil, pasar, teknikal,
  risiko semuanya tersedia. Tidak ada blokir.
- **Phase 2B (fundamental, keuangan, valuasi, growth, dividen):** bukan "tidak
  tersedia" — datanya ADA di sumber (yahoo), tapi `StockInfo`/provider hanya
  mengekspos sebagian. Prioritas: **perluas model data + pengambilan**, bukan
  integrasi sumber baru.
- **Phase 3 (market intelligence / berita):** tersedia sebagian — rekomendasi
  analis & sentimen teknikal (52-week change, moving average) ada; **berita
  tidak tersedia** dari sumber saat ini. Bagian berita harus graceful
  degradation ("data tidak tersedia") kecuali ada sumber baru.
- **Keputusan scope:** saham asing (AAPL) di luar jangkauan provider — laporan
  resmi mencakup emiten IDX.

## Rekomendasi Phase 0 — Research Report Foundation

1. Perluas model data saham: simpan field fundamental/valuasi/growth/dividen
   dari `stock.info` (opsional, jangan menunggu fetch — data sudah ikut).
2. Ambil `financials`, `balance_sheet`, `cashflow`, `dividends` sebagai data
   pendukung (lazy — hanya saat riset penuh diminta).
3. Berita tetap ❌ — desain section-nya sejak awal dengan graceful degradation.
