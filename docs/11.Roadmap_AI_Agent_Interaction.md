# Roadmap: AI Agent Interaction

## Overview

**Epic:** AI Agent Interaction

### Goal

Enable users to interact with the platform as they would with an intelligent research assistant. The AI should understand user intent, coordinate existing platform capabilities, and provide natural, context-aware interactions without requiring users to know specific commands or workflows.

---

# Phase 1 — Intent Understanding

## Objective

Enable the AI to accurately understand requests expressed in natural language.

### Scope

- Understand common investment requests.
- Recognize companies, sectors, markets, and comparisons.
- Interpret different ways of expressing the same intent.
- Detect ambiguous requests that require clarification.

### Expected Outcome

Users can communicate naturally without relying on predefined command syntax.

---

# Phase 2 — Intelligent Task Coordination

## Objective

Allow the AI to determine and coordinate the appropriate platform capabilities based on user intent.

### Scope

- Select the appropriate workflow.
- Combine existing platform capabilities.
- Reuse previous context when appropriate.
- Request clarification before making assumptions.

### Expected Outcome

The AI automatically performs the appropriate workflow while minimizing unnecessary user interaction.

---

# Phase 3 — Conversational Experience

## Objective

Provide a natural, continuous, and context-aware conversation.

### Scope

- Multi-turn conversations.
- Follow-up questions.
- Context-aware interactions.
- Consistent conversational behavior.

### Expected Outcome

Users experience interactions that feel like working with an intelligent research assistant rather than executing commands.

---

# Phase 4 — Agent Response Experience

## Objective

Deliver responses that are clear, structured, and appropriate for the user's request.

### Scope

- Clear and structured responses.
- Appropriate level of detail.
- Actionable recommendations.
- Consistent communication style.

### Expected Outcome

The AI produces responses that are easy to understand, trustworthy, and aligned with the requested task.

---

# Recommended Implementation Order

1. Intent Understanding
2. Intelligent Task Coordination
3. Conversational Experience
4. Agent Response Experience

---

# Success Criteria

- Users can complete common investment research tasks using natural language.
- The AI selects the correct workflow without requiring explicit commands.
- Conversations remain consistent across multiple interactions.
- Ambiguous requests are resolved through clarification rather than assumptions.
- Existing platform capabilities are reused instead of duplicated.

---

# Design Principles

- The AI Agent is the primary interaction model.
- Reuse existing platform capabilities.
- Avoid duplicate workflows.
- Keep interactions natural and intuitive.
- Remain implementation-agnostic.
- Deliver incremental improvements without unnecessary complexity.

---

# Out of Scope

This roadmap does not replace existing CLI commands. Command-based interaction remains fully supported while the AI Agent becomes an additional, more natural way to access the platform.

This roadmap also does not introduce new research capabilities. It focuses on making existing platform capabilities easier, more intelligent, and more conversational.

---

# Alignment with Product Vision

This roadmap establishes the AI Agent as the primary user interaction layer of the platform. It leverages the existing research, memory, and reporting capabilities to deliver a conversational investment research experience while remaining implementation-agnostic and avoiding unnecessary architectural complexity.

---

# Phase 5 — AI-first CLI Experience

## Objective

Make natural language the primary interaction model of the CLI while preserving the existing command-based interface for automation, scripting, and advanced users.

### Scope

- Natural language becomes the default interaction model.
- Existing CLI commands remain fully supported.
- Preserve backward compatibility.
- Reuse all AI Agent capabilities developed in previous phases.
- Improve the CLI entry experience without changing existing AI workflows.

### Expected Outcome

Users can launch the application and immediately interact with the AI using natural language without needing to remember CLI commands.

---

## Recommended Features

### AI-first Entry Experience

Launching the application starts an AI interaction session.

```text
$ screening

> Analyze BBCA

> Compare BBCA with BBRI

> Find undervalued banking stocks
```

Users no longer need to invoke a dedicated natural-language command before interacting with the AI.

Existing command-based workflows remain fully supported.

```text
screening analyze BBCA
screening compare BBCA BBRI
screening research BBCA
```

---

### Natural Language as the Default

Natural language becomes the primary way users interact with the application.

Command-based interaction remains available but is no longer the primary user experience.

---

### Unified Entry Point

Provide a single entry point for AI interaction.

Users should not need to decide between multiple conversational commands before talking to the AI.

The application itself becomes the AI interface.

---

### Reuse Existing AI Agent

The CLI should reuse all capabilities implemented in previous phases:

- Intent Understanding
- Intelligent Task Coordination
- Conversational Experience
- Agent Response Experience

without introducing duplicate workflows or duplicate business logic.

---

## Success Criteria

- Users can immediately start interacting with the AI after launching the application.
- Natural language becomes the default CLI interaction model.
- Existing command-based workflows remain fully backward compatible.
- No AI capability is duplicated.
- Existing workflows continue to operate without modification.

---

## Design Principles

- AI-first interaction.
- Preserve backward compatibility.
- Reuse existing AI architecture.
- Avoid duplicate workflows.
- Keep the interaction simple and intuitive.
- Deliver a seamless transition from command-based usage to conversational interaction.

---

## Out of Scope

This phase does not introduce:

- Terminal User Interface (TUI).
- Desktop or Web interface.
- New AI reasoning capabilities.
- Changes to parser, orchestration, conversation state, or response generation.
- New research workflows.

Its purpose is to improve the CLI interaction experience by making the AI Agent the primary entry point while reusing all capabilities developed in the previous phases.
