## 5. Analisis Gap

1. **Gap terbesar:** `StockInfo` (app/models/stock.py) menyaring 59 field fundamental menjadi 7 — data fundamental/valuasi/growth/dividen/rekomendasi analis sudah ikut di setiap fetch tapi terbuang di perbatasan model. Biaya membuka: rendah, tanpa panggilan ekstra.
2. **Data keuangan historis** butuh panggilan tambahan per saham → sebaiknya lazy (hanya saat riset penuh diminta).
3. **Berita: kosong permanen** sampai ada sumber baru (di luar scope roadmap ini).
4. **Kualitas campur:** beberapa field yahoo 0/null (beta, margins) → butuh filter nilai bermakna + aturan traceability.
5. **Scope geografis:** provider `.JK` → laporan resmi hanya emiten IDX.

---

## 6. Rekomendasi Urutan (fase berikutnya)

1. **Foundation:** perluas model data (simpan field fundamental/valuasi/growth/dividen dari info yang sudah ikut fetch) → buka 5 dimensi 🟡 tanpa sumber baru.
2. **Multi-dimensi tambahan:** ambil financials/BS/cashflow/dividends secara lazy untuk laporan penuh.
3. **Market intelligence:** hanya sentimen teknikal + rekomendasi analis; bagian berita = "data tidak tersedia" sampai ada sumber.
